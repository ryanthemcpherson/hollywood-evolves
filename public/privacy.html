Privacy

A plain account of what this preview does—and does not—collect.

Last updated August 30, 2026

No active accounts, analytics, or advertising profiles

LinkedIn commentary login is not active in this preview, so there are no active accounts. The site has no analytics, advertising trackers, or advertising cookies, does not sell personal data, and shows no cookie banner because it does not currently set analytics or advertising cookies.

An audience-signal backend exists for future open questions. Episode 01 is still a draft and not open, so it does not accept or publish responses. The public API currently returns empty, aggregate-only direct-forecast and LinkedIn-reaction totals.

Your private call stays on your device

If you choose Yes or No in the private question, the browser stores that choice in localStorage under the key he-private-forecast when browser storage is available. The choice is not a calibrated probability and is not sent to Hollywood Evolves, published, or counted. You can remove it with “Clear my choice” on the homepage or by clearing site data in your browser.

Sharing features

The Share this draft question button may use your device’s Web Share feature or clipboard. It shares the canonical question page, not your private Yes or No choice. Those actions occur only after you activate the button. If neither feature is available, the site shows a URL for you to copy yourself.

When an audience question opens

An open question will ask for an explicit Yes or No answer and may accept an optional confidence from 1% to 99%. Submission records the answer, confidence when provided, and a broad source label such as site, newsletter, QR, or LinkedIn. The public API returns aggregate-only totals separated by source. It never returns browser or import identifiers.

To enforce one response per browser, the site creates a random browser token in local storage. The server stores only a keyed, hashed browser token and a keyed idempotency hash; it does not ask for a name, email address, or LinkedIn profile. Closing or selecting “Not now” suppresses the modal for that browser session without submitting an answer. Normal hosting security logs may still process network metadata as described below.

LinkedIn reactions are reported separately from direct forecasts and are not treated as confidence or probability forecasts. Approved or manual imports retain only a keyed hash of a reaction ID, its mapped Yes/No value, campaign, and audit metadata—not the reacting member’s identity.

Hosting and fonts

Like normal web infrastructure, the hosting provider or content-delivery network may process security and access logs containing an IP address, browser or device information, the requested URL, and timestamps. This site currently loads Google Fonts from Google, which means Google may receive normal request metadata when your browser requests those files.

This statement is limited to the current repository and preview. It does not make claims about systems or services outside this implementation.

LinkedIn commentary controls

When activated, Sign in with LinkedIn requests the openid, profile, and email scopes. The service may receive a LinkedIn subject identifier, name, profile image URL, optional email address, and optional email-verification flag. It stores an opaque hashed session record in restricted application storage and sets Secure, HttpOnly, SameSite cookies. Sessions expire after seven days. Account and submission records otherwise remain until member deletion or editorial removal.

Written perspectives remain pending until an editor approves them. Submission requires explicit consent to publish an approved perspective with the member's LinkedIn display name. The public output excludes email addresses, LinkedIn subject identifiers, and profile-image URLs. A signed-in member can permanently delete the account and every pending, rejected, or published submission; PII-bearing audit entries are removed and only a keyed deletion receipt remains.

LinkedIn authentication must not be described as identity verification. A verified-industry designation requires separate editorial review. Privacy questions can currently be shared through the same channel used to access this preview.
